# Практична робота №6

## Тема
Створення анімації засобами мови C#.

## Опис роботи
У межах практичної роботи створено анімацію кольорового зображення машинки, побудованого методом базової точки.

У програмі реалізовано:
- побудову кольорового зображення машинки;
- використання компонента Timer;
- обробку події Tick;
- переміщення машинки шляхом зміни координати базової точки;
- повторне перемальовування форми методом Invalidate();
- циклічний рух машинки по формі.

- Visual Studio 2022

- Windows Forms
